# Фотографии сайта

Загружайте изображения в соответствующие папки и сохраняйте точные имена файлов из инструкции. Формат: JPG/JPEG или WebP; рекомендуемая ширина — от 1200 px для главного фото и проектов, от 700 px для карточек услуг. Не используйте пробелы и кириллицу в именах.

После загрузки в корень сайта должна попасть папка images со всей структурой. Если фото ещё нет, соответствующая ячейка останется без изображения — остальные разделы продолжат работать.
